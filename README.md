# CRM и График монтажей — Visma Mebel

Рабочее приложение мебельной компании: сделки и клиенты, график замеров,
доставок и монтажей, склад приходов с фабрики, задачи, напоминания, отчёты
и документы. Работает на своём домене **https://тверь-рецепт.рф**
(хостинг reg.ru, PHP) — данные одни и те же на компьютере и телефоне.

> Подробное описание приложения: [`crm-schedule/README.md`](crm-schedule/README.md).
> Как устроен деплой на домен: [`docs/HOSTING.md`](docs/HOSTING.md).

## Что внутри

| Часть | Где | Что это |
|---|---|---|
| Приложение | `crm-schedule/` | React + TypeScript + Vite, PWA (устанавливается на телефон) |
| Сервер | `server/api/index.php` | Весь бэкенд одним PHP-файлом: вход по паролю, сотрудники и роли, общая база, файлы вложений |
| Деплой | `.github/workflows/deploy-hosting.yml` | Сборка и загрузка на хостинг по FTP при каждом обновлении `main` |

## Возможности

- **CRM**: сделки, клиенты, воронка, доска, задачи со сроками и повторами.
- **График**: замеры, доставки, монтажи и свободные события (отпуск,
  совещание, выезд) — с повторами каждую неделю/месяц и проверками накладок.
- **Склад**: приходы с фабрики по ведомости (фото или PDF), остатки упаковок.
- **Напоминания**: о задачах, событиях графика, днях рождения и остатках.
- **Сотрудники и роли**: руководитель, менеджер, монтажник; у каждой роли
  свой доступ к деньгам и настройкам — проверяется и на сервере.
- **Файлы**: вложения сделок и клиентов доступны со всех устройств.
- **Данные**: экспорт/импорт JSON и ZIP с файлами, версии базы на сервере.

## Разработка

```bash
cd crm-schedule
npm ci
npm run dev    # локальная разработка
npm test       # тесты
npm run build  # сборка
```

Без сервера (например, на GitHub Pages) приложение работает в локальном
режиме: данные хранятся в браузере, общая база — через Supabase.
На своём домене сервер находится автоматически, и вход выполняется
по учётным записям сотрудников.

## Деплой

Слияние в `main` запускает публикацию: тесты → сборка → загрузка по FTP.
Проверка доставки: открыть `https://<домен>/build.txt` — там дата и коммит.
Данные сервера (`api/data/`) деплой не трогает.
