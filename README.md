# МойДень — персональный AI-органайзер

Единая система управления жизнью и рабочими делами: календарь, задачи, напоминания,
заметки, проекты, поездки, доставки, автоматические цепочки задач и AI-планирование.

Это **не CRM** и не обычный таск-менеджер. Главный принцип:

> **Я говорю, что происходит — система организует это.**

Пишете обычным языком: *«Завтра утром съездить на склад, забрать фасады, потом
отвезти их на объект, а вечером не забыть позвонить клиенту»* — система разбирает
фразу на действия, определяет время, длительность и зависимости, предлагает план
и создаёт его после подтверждения.

## Возможности (MVP)

- **Сегодня** — сейчас / далее / таймлайн со свободными окнами / требует внимания /
  свободное время, утренний брифинг и вечерний разбор.
- **Календарь** — день (основной), 3 дня, неделя, месяц, список.
- **Задачи** — универсальная сущность с типами (задача, событие, поездка, покупка,
  доставка, работа, личное, звонок, встреча), статусами, приоритетами, дедлайнами,
  жёсткие/гибкие (fixed / flexible / deadline), подзадачи, **зависимости**,
  **повторения**, перенос-счётчик.
- **Проекты** — контейнеры для чего угодно: прогресс, «следующее действие», пауза,
  заметки, история.
- **Заметки** — быстрые (мгновенно, без выбора чего-либо) и привязанные; конвертация
  в задачу.
- **Шаблоны** — Доставка, Монтаж, Новый клиент (лид→замер→…→монтаж), Поездка,
  ТО автомобиля; генерируют цепочку задач с зависимостями и смещениями в рабочих днях.
- **Автоматизации** — КОГДА (задача завершена + условия) → ТОГДА (создать задачу
  через N рабочих дней / напоминание).
- **AI-ассистент** — разбор фраз, команды («перенеси на пятницу», «напомни через
  3 дня», «поставь в приоритет», «разбей на 3 задачи»), вопросы по реальным данным
  («что у меня сегодня?», «что я забыл?», «когда есть три свободных часа?»),
  «Распланировать день», «Разгрузить день». **Ничего не меняет без подтверждения.**
- **История** — все действия: создано, изменено, перенесено, выполнено, отменено,
  пауза, автоматизации.
- **Мобильная версия** — нижняя навигация + большая кнопка «+», AI доступен отовсюду.
- **Аналитика** — выполнено по дням, распределение по категориям и типам,
  «хронически переносимые» задачи, прогресс проектов.
- **Дизайн** — премиальная тёмная боковая панель, светлая и тёмная темы,
  типографика Manrope/Inter, микроанимации; живые напоминания в интерфейсе.
- **Telegram-бот** — напоминания, утренний брифинг и вечерний разбор в чат,
  постановка задач текстом с подтверждением инлайн-кнопками (см. ниже).
- **PWA** — устанавливается на телефон как приложение, офлайн-оболочка.
- **Склад** — остатки материалов/фурнитуры, приход/расход, минимальные запасы.
- **Файлы** — вложения к задачам и проектам (чертежи, сметы, фото).
- **Дорога** — подсказка «выезд в …» для поездок/встреч (время из справочника мест).
- **Голосовой ввод** — диктовка фраз ассистенту (Web Speech API, ru-RU).
- **Drag & drop** — перетаскивание задач между днями в календаре.

Подробности архитектуры — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Telegram-бот

1. В Telegram откройте **@BotFather** → `/newbot` → получите токен.
2. В приложении: **Ещё → Настройки → Telegram-бот** — вставьте токен.
3. Откройте своего бота и отправьте `/start` — чат привяжется автоматически.

Дальше бот сам присылает напоминания, уведомления за N минут до задач,
утренний брифинг и вечерний разбор (время настраивается). Можно писать боту
обычным языком («завтра утром съездить на склад…») — он предложит план и
создаст задачи только после подтверждения. Команды: `/today`, `/tomorrow`,
`/brief`, `/evening`.

Токен хранится только в локальной базе (не в коде и не в git). Используется
long polling — публичный URL не нужен.

## Внешний LLM (опционально)

Встроенный разбор фраз работает без интернета. Для более умного разбора можно
подключить любой OpenAI-совместимый API через переменные окружения сервера:

```bash
LLM_API_KEY=sk-...            # включает адаптер
LLM_API_URL=...               # по умолчанию https://api.openai.com/v1/chat/completions
LLM_MODEL=gpt-4o-mini         # по умолчанию
```

При недоступности LLM система молча откатывается на встроенный парсер.
Вопросы-ответы («что у меня сегодня») всегда отвечаются из реальных данных БД.

## Запуск

Требования: Node.js ≥ 22 (используется встроенный `node:sqlite`).

```bash
# Backend (порт 3001) — задайте свой часовой пояс, чтобы брифинги приходили вовремя
cd server && npm install && TZ=Europe/Moscow npm run dev

# Frontend (порт 5173, проксирует /api на 3001)
cd web && npm install && npm run dev
```

Продакшен: `cd web && npm run build` — сервер сам раздаст `web/dist`
(`cd server && npm start`, всё на одном порту 3001).

## Данные и секреты

- База — SQLite-файл `server/data/organizer.db` (в `.gitignore`).
- Никакие ключи/токены в репозитории не хранятся. Внешний LLM подключается через
  переменные окружения `LLM_API_URL` / `LLM_API_KEY` (см. `server/src/services/nl/llm.js`).
