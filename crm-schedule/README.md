# CRM + График монтажей

Отдельное приложение, в которое вынесены **CRM** и **график монтажей** из репозитория
калькулятора (`silovr709-dotcom/Calculator`). Больше не нужно открывать калькулятор,
искать вкладку CRM или график и держать десятки лишних экранов — здесь только клиенты,
сделки, задачи, оплаты и монтажи.

## Что внутри

**CRM**
- Сделки: 11 этапов от «Черновика» до «Выдано»/«Отказа», сумма, ответственный,
  следующий шаг и дата следующего контакта.
- Фокусы: «Сегодня и просрочено», «На неделе», «Без следующего шага», активные,
  закрытые, все. Воронка из пяти этапов с суммами.
- Два вида: список с сортировкой по срочности/сумме/изменению и **доска**
  с перетаскиванием сделок между этапами.
- Карточка сделки: контакты, задачи, оплаты, график и история в одном окне.
  Текст сообщения клиенту под текущий этап + WhatsApp/звонок/SMS в один клик.
- Клиенты: карточка с контактами, тегами, заметками и всеми сделками.
- Задачи по сделкам: звонки, встречи, замеры, документы, оплаты, монтаж.
  Срочность считается автоматически (просрочено/сегодня/скоро).
- Оплаты: предоплата, доплата, доп. работы, возврат; остаток и прогресс оплаты.
- Автоматика: 5 правил («Позвонить после КП», «Договор после согласования»,
  «Запросить предоплату», «Позвонить после монтажа», «Сделка зависла») сами ставят
  задачи. Настраиваются в «Данных».

**График монтажей**
- Месяц и неделя; события четырёх типов: замер, готовность на фабрике, доставка, монтаж.
- Многодневные монтажи, бригады, адреса, телефоны, заметки для бригады, статусы
  (запланировано / подтверждено / выполнено / проблема).
- Перетаскивание события на другой день мышью — дата в сделке меняется сразу.
- Проверки: монтаж раньше готовности, доставка позже монтажа, нет адреса или бригады,
  бригада занята в двух местах одновременно.
- Загрузка бригад, маршрут по адресам дня (Яндекс.Карты), ближайшие 14 дней.
- Экспорт `.ics` — график подписывается в календаре телефона.

**Обзор**
- Портфель, контакты на сегодня, монтажи недели, оплаты за месяц, задачи.
- Списки «Связаться сегодня», «График на 10 дней», «Задачи», предупреждения графика
  и прогресс оплат по активным сделкам.

## Запуск

```bash
cd crm-schedule
npm install
npm run dev        # http://localhost:5173
```

Сборка и проверки:

```bash
npm run build      # tsc + vite build → dist/
npm test           # 53 теста логики и интерфейса (vitest)
```

При первом запуске загружается демонстрационная база (клиенты, сделки, платежи,
монтажи), чтобы сразу было видно, как всё работает. Её можно заменить своими данными
в разделе **Данные** — «Очистить всё».

## Данные

- Всё хранится в `localStorage` браузера, ключ `crm-schedule.v1`. Бэкенд не нужен,
  приложение можно выложить как статический сайт.
- Резервная копия — JSON (`Данные → Скачать .json`), импорт — там же.
- **Импорт из калькулятора:** в калькуляторе сделайте резервную копию
  (`kind: recept-backup`) и загрузите её в «Данных». Перенесутся клиенты, заказы,
  задачи, этапы и даты монтажа. Суммы берутся из сохранённых версий КП; если версий
  не было — сумму нужно один раз заполнить в карточке сделки.
  Поддерживаются старые статусы, ссылки на клиентов и многодневные монтажи.
- Экспорт `.ics` — для календаря iOS/Android.

## Как выносили

Исходные модули в ветке калькулятора `arena/78834e40-calculator`:

| Что | Откуда |
|---|---|
| Статусы и правила CRM | `app/src/lib/crm.ts` |
| Воронка, фильтры, сводка | `app/src/lib/crmBoard.ts` |
| Задачи и оплаты | `app/src/lib/crmTasks.ts` |
| Лента сделки | `app/src/lib/crmTimeline.ts` |
| Автоматические правила | `app/src/lib/crmAutomation.ts` |
| График и проверки | `app/src/lib/schedule.ts` |
| Экраны | `app/src/components/CrmView.tsx`, `CrmDealDialog.tsx`, `CrmClientDialog.tsx`, `ScheduleView.tsx`, `ScheduleDialog.tsx` |

CRM в калькуляторе была жёстко связана с прайсом и расчётом кухни: сумма сделки
считалась движком, документы — через пакет КП, график — через календарь проектов.
В отдельном приложении своя модель `Client → Deal → задачи/оплаты/график`, поэтому
модули работают без прайса, а суммы вводятся вручную. Логика фильтров, срочности,
воронки, автоматики и проверок графика сохранена и покрыта тестами.

## Структура

```
crm-schedule/
  src/
    App.tsx                 — навигация, карточки, автоматика при старте
    store.tsx               — состояние, сохранение, уведомления
    types.ts                — клиенты, сделки, задачи, оплаты, график
    lib/
      crm.ts                — этапы, следующий шаг, срочность контакта
      crmBoard.ts           — воронка, фокусы, сортировка, строки
      crmTasks.ts           — задачи и платежи
      crmTimeline.ts        — история сделки
      crmAutomation.ts      — правила автоматики
      schedule.ts           — события, сетки, проверки, загрузка бригад
      metrics.ts            — цифры обзора
      storage.ts            — localStorage, JSON, ICS, импорт калькулятора
      demoData.ts           — демо-база
    components/             — экраны и карточки
```
