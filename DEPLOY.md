# Как поселить «МойДень» в облаке (инструкция для человека, а не для программиста)

Цель: приложение работает круглосуточно, открывается с телефона и компьютера,
данные не пропадают при перезапусках, Telegram-бот пишет вам утром и вечером.

Оплата — картой РФ в рублях, доступ из России без VPN.

Рекомендуем **Amvera Cloud** — там всё делается мышкой за 15 минут.
Ниже — подробный путь для Amvera, а в конце — запасной вариант (Timeweb Cloud).

---

## Что уже готово в проекте

В репозитории лежат три файла, которые нужны облаку. Трогать их не надо:

| Файл | Зачем |
|---|---|
| `Dockerfile` | Инструкция «как собрать и запустить приложение» |
| `amvera.yml` | Настройки Amvera: порт 3000 и постоянный диск `/data` |
| `.dockerignore` | Что не тащить в облако (лишние файлы) |

Важно: база данных и загруженные файлы сохраняются в папку **`/data`** — это
«несгораемый шкаф» облака. При перезапуске и при обновлении кода данные остаются.

## Вариант 1. Amvera Cloud (рекомендуем)

### Шаг 1. Регистрация

1. Откройте <https://cloud.amvera.ru>.
2. Нажмите **Регистрация**, заведите аккаунт (почта или Телеграм).
3. Зайдите в раздел **Баланс** и пополните счёт картой РФ.
   Хватит минимального тарифа: ~1 ГБ памяти. Ориентир — несколько сотен рублей в месяц.

### Шаг 2. Создаём приложение

1. Слева нажмите **Проекты** → кнопка **Создать** → тип **Приложение**.
2. Имя проекта: `myday` (любое латиницей).
3. Тариф: самый дешёвый «Начальный» — этого достаточно.
4. На шаге «Загрузка данных» выберите **Подключить через Git / GitHub**
   и укажите ваш репозиторий с этим кодом (ветку `main` или ту, где лежит код).
   Если Amvera попросит доступ к GitHub — разрешите.
5. На шаге «Конфигурация» ничего вручную заполнять не нужно:
   Amvera увидит файл `amvera.yml` в репозитории. Просто нажмите **Завершить**.

### Шаг 3. Пароль администратора (важно!)

Пароль нельзя хранить в GitHub. Задаём его прямо в облаке:

1. Откройте созданное приложение → вкладка **Переменные** (Environment / Настройки).
2. Добавьте переменные:

   | Имя | Значение | Комментарий |
   |---|---|---|
   | `ADMIN_LOGIN` | `admin` | ваш логин для входа (можно оставить admin) |
   | `ADMIN_PASSWORD` | ваш надёжный пароль | придумайте сами, никому не показывайте |
   | `TZ` | `Europe/Moscow` | московское время |

3. Нажмите **Сохранить** и затем **Пересобрать** (кнопка «Собрать»/«Rebuild»).

Если переменные не задать, приложение создаст администратора с логином `admin`
и временным паролем `admin` — при первом входе оно само потребует сменить пароль.

### Шаг 4. Включаем домен

1. Вкладка **Настройки** → раздел **Домены** → **Добавить бесплатный домен Amvera**.
2. Получите адрес вида `myday-вашлогин.amvera.io`.
3. Через 1–2 минуты откройте этот адрес в браузере — увидите окно входа.

### Шаг 5. Первый вход и пользователи

1. Войдите: логин `admin`, пароль — тот, что задали в переменной `ADMIN_PASSWORD`.
2. Откройте **Ещё → Пользователи → + Пользователь** и заведите жену и мастера Сергея:
   логин латиницей, имя по-русски, пароль (потом они смогут сменить его сами
   в разделе «Ещё → Мой аккаунт»).
3. У каждого пользователя свои задачи, проекты, заметки, напоминания и свой Telegram.

### Шаг 6. Установить как приложение на телефон

Откройте адрес в Chrome (Android) или Safari (iPhone) → меню браузера →
**«Установить приложение»** / **«На экран Домой»**. Появится иконка, как у обычного приложения.

### Шаг 7. Telegram-бот (работает круглосуточно)

1. В Телеграме найдите **@BotFather** → команда `/newbot` → придумайте имя и адрес бота.
2. BotFather пришлёт длинный токен вида `1234567890:AA...`.
3. В «МойДень»: **Ещё → Настройки → Telegram** → вставьте токен → **Сохранить**.
4. Напишите своему боту любое сообщение (например `/today`) — приложение
   само запомнит ваш чат и начнёт присылать утренний и вечерний план.
5. Каждый пользователь может подключить **своего** бота — сообщения не перепутаются.

Пока приложение работает в облаке (а оно работает 24/7), бот отвечает всегда,
даже если у вас закрыт браузер и выключен компьютер.

### Обновление в будущем

Меняете код на GitHub → в Amvera на странице приложения жмёте **Собрать** →
через пару минут новая версия онлайн. Данные в `/data` при этом сохраняются.

### Резервная копия данных

В Amvera на странице приложения откройте **Репозиторий → папка data** — там
лежит файл `organizer.db`. Его можно скачать: это полная копия всех ваших данных.
Раз в месяц скачивать такую копию — хорошая привычка.

## Вариант 2. Timeweb Cloud (если Amvera не подошла)

Timeweb тоже российский, оплата в рублях. Тут два пути.

### 2а. App Platform (просто, мышкой)

1. Зарегистрируйтесь на <https://timeweb.cloud>, пополните баланс.
2. **Создать → Приложение → Docker (Dockerfile)**.
3. Подключите GitHub-репозиторий, ветку с кодом. Dockerfile платформа найдёт сама.
4. Тариф: минимальный (1 ядро / 1 ГБ).
5. В разделе **Переменные окружения** добавьте:
   `ADMIN_PASSWORD` = ваш пароль, `TZ` = `Europe/Moscow`, `DATA_DIR` = `/data`.
6. Подключите **постоянный диск (volume)** и укажите точку монтирования `/data`.
   Это обязательный шаг: без него база сотрётся при пересборке.
7. Нажмите **Развернуть**, дождитесь статуса «Запущено», откройте выданный адрес.

### 2б. Обычный сервер VDS (надёжнее, но нужен терминал)

1. **Создать → Облачный сервер**, образ **Docker**, тариф от 1 ГБ RAM.
2. Подключитесь к серверу через «Консоль» в панели Timeweb и выполните:

   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/CRM.git myday
   cd myday
   docker build -t myday .
   docker run -d --name myday --restart always \
     -p 80:3000 \
     -v /srv/myday-data:/data \
     -e ADMIN_PASSWORD='ваш_пароль' \
     -e TZ=Europe/Moscow \
     myday
   ```

3. Откройте в браузере IP-адрес сервера.
4. Данные лежат на сервере в папке `/srv/myday-data` — при перезапуске
   контейнера и перезагрузке сервера они остаются (`--restart always`
   поднимает приложение автоматически).

## Частые вопросы

**Данные точно не потеряются?**
Да, если база лежит в `/data` (Amvera) или в подключённом диске (Timeweb).
Приложение записывает туда файл `organizer.db` и все вложения.

**Что если забыл пароль администратора?**
Поменяйте переменную `ADMIN_PASSWORD` в панели облака и пересоберите приложение —
пароль администратора обновится при старте.

**Можно ли пускать чужих?**
Нет. Публичной регистрации в приложении нет вообще: новые пользователи
появляются только через раздел «Ещё → Пользователи» у администратора.

**Пароли и токены в GitHub попадут?**
Нет. Всё секретное живёт в переменных окружения в панели облака,
а файлы `.env` и папка `server/data` исключены через `.gitignore`.

## Переменные окружения — шпаргалка

| Переменная | Для чего | Пример |
|---|---|---|
| `ADMIN_LOGIN` | логин администратора при первом запуске | `admin` |
| `ADMIN_PASSWORD` | его пароль | `Ochen-Slozhnyi-2026` |
| `DATA_DIR` | где хранить базу и файлы | `/data` |
| `PORT` | порт приложения внутри контейнера | `3000` |
| `TZ` | часовой пояс | `Europe/Moscow` |

Telegram-токен через переменные задавать не нужно — он вводится в самом
приложении, у каждого пользователя свой.
